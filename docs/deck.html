Slide 01 / 08 · Problem & Target Users

Why Factory Lines Stop Even When the ERP Shows "Shipped On Time"

Target User: Operations & Supply-Chain Resilience Leads managing high-value automotive and power-electronics manufacturing lines ($52,000 to $78,000/hr downtime cost).

The Fragmented Data Trap

  • ERP (`zetaris_erp.purchase_orders`): Trusts vendor EDI 856 ASNs that mark `PO-8841` (4,000 SiC modules) as `SHIPPED_ON_TIME`.
  • Warehouse WMS (`zetaris_wms.inventory_ledger`): Physical dock scan shows only 350 unrestricted units (35.9h runway), 800 quarantined, and 2,850 missing.
  • Quality QMS (`zetaris_qms.incident_tickets`): Lab acoustic microscopy proves Sub-lot 992A-2 (800 units) has 18.4% solder-void failure, while Sub-lot 992A-1 (350 units) has 0.0% voids.
  • Carrier REST API (`zetaris_rest.carrier_port_feeds`): Ocean vessel carrying the remaining 2,850 units is held in customs (+96h delay).

One-Sentence APPROACH Problem Statement

We built an agent system (Switchyard) that helps an Operations Lead resolve critical supplier disruptions by querying four disconnected, conflicting systems through Zetaris, reconciling contradicting records in a shared Meterless World Model with an adversarial Conflict Critic, and producing a single sourced remediation order powered by NVIDIA Nemotron models through Meterless Nightshift.

Slide 02 / 08 · The Solution

Switchyard: Autonomous Multi-Source Reconciliation & Remediation

1. Cross-System Truth

  • Queries ERP, WMS, QMS, Carrier REST feeds, and Qualified Suppliers through Zetaris using single-statement Lightning SQL.
  • Flags every cross-source contradiction automatically and resolves them using 3-way empirical corroboration.

2. Adversarial Critic Loop

  • Not a linear pipeline: when the Reconciler proposes a draft after Round 1, the Conflict Critic Agent rejects it if QMS lab evidence or backup capacity is missing.
  • Forces targeted Round 2 SQL queries before signing off (`APPROVED_WITH_PROVENANCE`).

3. Deterministic Action

  • Sizes exact emergency PO splits across qualified backup suppliers (`2,400 units Silicore Dresden + 1,250 units Pacific Semi`).
  • Saves $3.82M in net factory downtime on `PO-8841` alone.

Slide 05 / 08 · How Zetaris & Meterless Were Integrated

Deep, Load-Bearing Sponsor Integration (With Passing Conformance Tests)

Zetaris Unified Semantic Layer

  • Federates 5 operational tables (`zetaris_erp.purchase_orders`, `zetaris_wms.inventory_ledger`, `zetaris_qms.incident_tickets`, `zetaris_rest.carrier_port_feeds`, `zetaris_erp.qualified_suppliers`) plus the starter `pokeapi` validation table.
  • Enforces the Zetaris `AGENTS.md` single-statement rule in code and verifies it in `test_01_zetaris_single_statement_rule`.

All 4 Meterless Engines in Working Features

  • Scout Intent: Classifies disruption type, scores risk (95/100 CRITICAL), and selects Zetaris tables + Nemotron lanes.
  • World Model: Versioned entity/conflict graph (v1 to v15) with optimistic concurrency control (`ConcurrencyConflictError`).
  • Markovian: Compresses 6-step context from 7,612 naive tokens to 1,216 bounded tokens (84.0% reduction).
  • H-MEM: Recalls Q3 supplier precedents before the run and commits newly verified remediation rules to disk after the run.
Slide 06 / 08 · Unique Innovation with Sponsor Technologies

Dual-Lane NVIDIA Nemotron Routing + Markovian-Bounded Critic Loops

1. Hardware-Aware Dual Nemotron Lanes

  • Instead of routing every agent turn to a single model, Switchyard pairs **Nemotron 3.5 Lightning 30B** (high-speed tool calling and Zetaris SQL generation on Lane 1) with **Nemotron 3.5 Super VL 120B** (adversarial Conflict Critic, risk escalation, and final provenance synthesis on Lane 2) through **Meterless Nightshift**.
  • Every single agent step emits a signed `ModelReceipt` proving which Nemotron model handled the request.

2. Zero-Clobber World Model + Markovian State

  • Multi-agent loops normally degrade as raw SQL outputs pollute the prompt window. By combining **Meterless World Model** (structured conflict state) with **Meterless Markovian** (bounded carry-over capsules), our 6-step critic loop cuts prompt tokens by **84%** while maintaining 100% citation accuracy.
